# Personal Portfolio

A responsive, single-page portfolio built with plain HTML, CSS, and JavaScript.

## Open the website

Open `index.html` in Google Chrome. You can also right-click `index.html` in File Explorer and choose **Open with → Google Chrome**.

## Files

- `index.html` contains the page structure and editable portfolio copy.
- `styles.css` contains the visual design and responsive layouts for mobile, tablet, and desktop.
- `script.js` provides the mobile navigation toggle and updates the footer year automatically.

## Personalize it

Search `index.html` for `Your Name`, `Your City`, and `hello@example.com` and replace the placeholders. Update the sample project cards, skill tags, service descriptions, and social profile links with your own details. The font is loaded from Google Fonts when an internet connection is available; the page otherwise falls back to system fonts.
